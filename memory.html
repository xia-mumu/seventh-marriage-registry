MEMORY PROTOCOL · 映境記憶管理

三式憶籍

每次入世前，均可選擇當次映境的記憶模式。
不影響魂籍本體，亦不永久刪除現世記憶。

MEMORY · I
共憶 ｜記得彼此

保留現世與冥府的記憶，清楚知道自己正身處映境。即使換了身分，也記得原本的自己與同行者。

MEMORY · II
封憶 ｜此生初見

在該映境期間，暫時無法取用現世與冥府記憶，依映境身分生活；這不代表兩人在世界內必然相識。

MEMORY · III
漸憶 ｜故人似曾相識

入世時記憶暫不完整，隨映境經歷、線索或情境逐步恢復，不預設固定的恢復時刻。

承辦附註：記憶模式逐境選擇。返回冥府後，魂籍本體與現世身分恢復可用，各映境經歷另行留存。本處不負責替當事人忘記尷尬發言。
